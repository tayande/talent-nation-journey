## Tier 5 work
### The completed chain is:
customer input --> application/program --> instructions --> data processing --> stored data --> result
### What is the computer doing?
The computer here is in charge of executing the instructions given to it by the program, using the data that is coming in from the user or customer, it is going to execute and store the result as directed by the program.

### What is the program doing?
The program is what literally contains the instructions or is itself the instructions that the computer is going to follow in order work on the data that the customer is providing to process his or her order. The series of steps, the verification that is going to happen with the input data, the decisions the computer will have to make at some points are all made available to the computer through the program. It is simply what tells the computer what to do and how to do it.
### What data is involved?
The data involved here is the information the customer passes into the application as he tries to make an order and then the data regarding what and what is in the store from which the customer is ordering. Examples include: His name, email, address, what he is buying, how much he has paid for it, the time of intended delivery, available stock and the price or each item. The computer will work with the data using the instructions provided by the program and the order will be processed.
### What instructions are being executed?
The instructions that are being executed are the ones provided by the program. Execution here is the process by which the computer takes the instructions given by the program and uses works according to them to produce a given result. Now this instructions include:
- get customer details
- get customer's order
- check that there’s enough in stock for the quantity requested.
- if not available, tell the customer
- if available, calculate the cost of the order (price × quantity).
- ask the customer for delivery address
- add up the transport fee for delivery to the cost of the customer's order
- return the total cost of the order to the customer, with the delivery date
- if the cost or the delivery data does not work for the customer then END
- if it works for the customer then ask for his or her card or any other payment method
- process the payment
- if payment fails, return the message to communicate the failure and END
- If the payment goes through, return a success message to the customer
- add the order to to-deliver list
- update the inventory given that an item or some items from the store have been paid for
These are instructions the computer is going to follow to ensure that an order is processed.

### What is the output?
What ever it is that is the resulting factor after the computer executes the instructions provided by the program using the data that the customer has entered, is what is said to be the output. In this case, if the order went through, then the computer returns a "order successfully placed" message, and if an order fails to be successful, the computer would still return a meaningful message and stating whatever reason that made the order to fail. The result of the execution is what is known as the output.
### What must be stored so the system remembers the order?
This covers the details the computer would use to remember a particular order by, such details include:
- name of customer
- content of his or her order
- quantity ordered
- the delivery address 
- date of delivery
- date of order 
- amount paid for the order
- order status (e.g. paid, awaiting delivery, delivered)

If there is a name that is represented as a number from the instructions, then the computer would have to recognize such a name as a number because it is only following the program's instructions.
The computer is not able to understand the real world simply because it only has the data it is given, so there is so much limitation to what the computer can do and can understand given that it is never given all the data to do so.
