### Identifying the type of each piece of data
- Customer name: Victor
This is used or represented by the computer as text, which is defined as a sequence of characters. Once the computer has seen this as a text, it cannot treat it as a number since they are two different representations and they have different operations.
- Age: 30
This is used or represented by the computer as a whole number. It is specifically a whole number because there is a difference between 30 and 30.0 so far as the computer is concerned. Given that it is a literal dumb machine. And the reason why age is represented in numbers is because age is counted in whole years.
- Account balance: 150000.50
This is used or represented by the computer as a decimal number. like i mentioned in the earlier point, 150000 is not the same as 150000.00 so far as the computer is concerned, and they are both treated as different forms of data, and must be represented differently.
- Account active: Yes
This is represented by the computer as a boolean form of data. When we talk of boolean, we are implying about only two possible outcomes, which are true and false, and the computer happens to be literal and aware about them, so a condition or a situation that requires to be represented in this form can only be true or false. Remember that "yes" also looks like a normal text and can be written in several ways, such as "yeah", "yep" etc, so the computer has only one way of representing all of them which is using the boolean value of it.

### Why each data needs a unique representation by the computer
This is because the computer deals basically with data, it takes it as inputs, processes it and returns an output which is itself in form of data still. The unique representation of data makes it possible for the computer to differentiate and process such data in the way it is programmed to. For instance, there are particular operations the computer can perform on a text but cannot perform on a number, so a wrong representation of text can result in a wrong operation on the text.

### The chain of data representation 
When they talk of a chain, it is simply the series of steps that a particular data passes through for it to be recognized by the computer in any form at all. below is the chain further explained in details.
- real-world information: This is the data form that is understandable by the human eye, when you see the name "Victor", the human mind already knows what it is (which is a text). So for any information or a data form that the human eye understands, that is the real-world information which happens to be the first step of data form 
- Data representation: This is the stage where a particular data in the earlier form is attached to represent something. for instance, you know that "victor" is a text, then attaching it to someone and saying its the person's name is what makes the name "victor" a representation of the person. 
- digital: This makes more sense when it is explained in computer terms, the data type of an item is how the computer recognizes the item on the basis of the operations that item can undergo. For instance an item that has been labeled as a text by the computer, when such an item undergoes an operation that can only be performed on a number, the computer would fail at such an operation.
- Binary: This is the data form that is more understandable by the computer than the human eye, it reduces all the data to a level that the computer can store and work with. This is because literally or by default, the computer only understands binary, and it is the form in which it stores all the data that it works with. This is not what is necessary for the user or programmer to do since the computer does it on it's own. All the data that we feed the computer with all the forms and representations, this is the final form the computer converts the data to before it works with. For instance, you create a variable and assign "Victor" to it, then the computer is the one that takes the variable's representation and stores it in the form it will understand and work with, and that form is known as the binary form (which is basically 1's and 0's)
- stored: This is the stored data, remember it is stored in binary form, so this exists here to tell that the computer has where and how it stores each of the data that it receives. so when a particular data that is given to the computer is referenced and the computer needs to work with it, it goes to the particular address that the data is in memory and grabs it right away.

### Reasoning challenge
If a particular data is read wrongly maybe due to the user or the programmer assigning the wrong values or representation to the data, the computer is just a dumb literal machine that would only perform its operations on the kind of data and representation it is being fed, so having the wrong data representation would never yield the desired result. For instance: if an amount that is supposed to be read and represented as 10000 is by mistake read as a much lower or higher amount, then whatever logic it is that was written with respect to the amount would produce the wrong outcome. Here is one practical example to take note of:
Using the ATM scenario in tier 2, assuming the available account balance linked to a card is read wrongly, the actual balance is 150000.50 and the computer reads it as 15000050 missing the decimal and assuming the person tries to withdraw 1500000, and instead of the ATM to return an "insufficient balance" response to the person right away, it would go ahead with the transaction on the basis that the person can withdraw that amount. This would result to a loss to the bank.
