### Key concepts
#### Readability
This covers writing instructions in a language that closely resembles humand english rather than computer hardware commands.
#### Ecosystem (libraries)
This is defined as a collection of pre-written instructions created by other programmers that you can plug into your own project to instantly add new features.
#### Versatility (multi-purpose)
This is the ability of a single language to handle many different types of tasks, from simple scripts to complex automation.
#### high-level and low-level programming languages
These two are different based on how close the language is to human thinking and understanding and then how close it is to computer's hardware. The higher the language, the closer it is for human understanding, the lower the language, the closer it is to the cpu or the computer hardware.
A high-level language is designed strictly to be easy for humans to read, write and understand. 
A how level language is much more closer to the understanding of the computer hardware. The language C is technically a high-level language but it is at times refered to as a low level language due to how it gives direct access to the memory. A high-level language is abstractive (it hides unnecessary details) and only exposes what it is that you need to work with alone. And note that low level langs are usually faster than high-level langs, reason being that low level langs have fewer layers between them and the computer hardware.
*** note ***
since highlevel langs are more understandable by humans, the computer needs a translator to interpret the human written instructions for it to understand what it is that the human wants. There are two types of tranlators:
- compiler: When we talk of a programming lang being a compile language, we mean that such a language needs the assistance of compiler to interpret the instructions written in such a language for the computer to understand what to do. A compiler translates the entire program before it runs. languages that use this include: Go, C, C++, Rust, etc
- Interpreter: when we talk of an interpreted language on the other hand, we mean that such a language requires the help of an interpreter for the instuructions written in it to be understood by the computer. This interpreter tranlates and executes the program while the program runs. How it behaves is that it starts running from top to bottom and once it encounters an error, it stops there ans points at where the error happened. some of the languages that fall under this category are: Python, Ruby etc.
