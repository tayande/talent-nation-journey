## LESSON 2.1: INTRODUCTION TO PYTHON (WHY PYTHON)
Python plays a very vital role by providing an english-like syntax that stands between human intent and machine code, telling the computer exactly what a humand being wants it to do. It's not only python that does this, the ability for a human to communicate with the computer and give it instructions is made possible by programming languages, and python happens to be one of such languages. Now for this lesson we are going to be focusing on why we would use python instead of any other language?. The following points justify why python is prefarrable to other programming languages:
- It is *** readable: *** In fact, it looks just like english language and it is easier for both humans and the computer to interprete instructions.
- It is *** beginner friendly:*** This means it is easy to learn, it is simple and it has clear rules.
- It is *** versatile: *** This means it can be used for a variety of tasks or operations such as: web development, Data science, AI and Automation
- It is *** popular: *** Of course being one of the easiest there is, it is well know among programmers
- It is *** interpreted: *** This means that it runs line by line and breaks whereever it encounters an error, and gives feedback instantly
- It *** has large library: *** This only shows how easy python has been made for it's users, it has a lot of built-in functions to speed up and enhance your experience when writing python code and performing tasks with python. 
- It is in all referred to as the perfect first programming language
### Key concepts
#### Readability
This covers writing instructions in a language that closely resembles humand english rather than computer hardware commands.
#### Ecosystem (libraries)
This is defined as a collection of pre-written instructions created by other programmers that you can plug into your own project to instantly add new features.
#### Versatility (multi-purpose)
This is the ability of a single language to handle many different types of tasks, from simple scripts to complex automation.
