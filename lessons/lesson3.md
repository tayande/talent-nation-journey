## LESSON 3.1: SETTING UP YOUR ENVIRONMENT (WITH BASH BASICS)
There are common concepts we need to understand here before moving forward.
#### Terminal/ClI
This is a text-only window where you type direct instructions to your computer's operating system instead of clicking icons.
#### Working directory
The specific folder you are currently working in or looking atl
#### path
The complete address of a file or folder, showing every folder you must open to reach it.
#### python interpreter
The software tool that reads your python code and translates it into actions the computer hardware can run or perform.
#### Step 1 
- Installing the Python Stamp (The Installation)
#### Step 2 
- Knowing Where You Stand (pwd and ls)
the  first command tells your where you stand and the later tells you how many files are in your position.
#### Step 3 
Moving and Creating (cd, mkdir, touch):
- cd (Change Directory): Moves your focus into a different folder.
- mkdir (Make Directory): Creates a brand new, empty folder.
- touch (Create File): Creates a blank index card (file) inside your current folder.
#### Step 4 
- Running a Script
when you have successfully created, and written a python code in a python file, all you need to do for you to run that code is: `python3.filename.py` and the code in that file will run and the result for the code will be shown to you.
