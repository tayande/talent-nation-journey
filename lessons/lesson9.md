## LESSON 9.1: CONTROL FLOW: CONDITIONALS
### Control flow
This is the order in which individual lines of code are executed by the computer. Normally the computer executes code line by line and that is the traditional control flow.
### if Statement
This is the primary decision gate. If a certain condition is true, then the computer runs the block of code in that condition.
### elif (Else If)
For any block of code that falls under this condition, the computer runs it only if the block before it was not true or was not met.
### else statement
This block executes only if the first conditions are not true. It works just like the default condition in the switch statement.
### Indentation 
This is a space that is given when a new block of code starts. So for any indented block, all the lines on that block belong to the same block.
